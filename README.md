# Formbuilder redesign

A lightweight TypeScript + React formbuilder prototype with a modern style and drag-and-drop field arrangement.

## Run

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
npm run dev
```

Optional Postgres:

```bash
export DATABASE_URL=postgresql://postgres:postgres@localhost:5432/formbuilder
```

Then start backend with the env var set.
